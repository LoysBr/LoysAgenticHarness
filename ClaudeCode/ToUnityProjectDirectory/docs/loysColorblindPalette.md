# Colors to use

Everywhere you need to use colors, in documentation, gizmo, materials etc, if you have the choice, use those colors. They are easy to distinguish for Loys who is colorblind. Use them in this order of priority.

- Yellow          │ #F0E442
- Electric Blue   │ #4A48FF
- Dark Red        │ #a80a0a
- Pink            │ #CF00B7
- Dark Blue       │ #291b6d
- Light Turquoise │ #0FCCD1
- Bright Green    │ #07c60a
- Dark Brown      │ #5D3A1A
- Sky Blue        │ #919cfe
- Dark Green      │ #086559
- Orange          │ #E69F00
- Gray Green      │ #7f8886
