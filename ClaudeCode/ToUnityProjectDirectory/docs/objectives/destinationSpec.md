# Destination Spec

The finished prototype, described as a result.

This document says **what the finished thing is and does** — what the player
sees, what a designer can author, and what each Module is responsible for. It
deliberately does **not** say how any of it is built: no types, no file formats,
no class shapes. Those decisions should instead be recorded in
`.scratch/destination-spec/DECISIONS.md` and become tickets. 

There is no release split here either. This is the whole destination; slicing it
into Releases happens afterwards, against this document, in [plan.md](plan.md).

Vocabulary is [CONTEXT.md](../../CONTEXT.md). Every capitalised term is defined
there and is used here in exactly that sense.
